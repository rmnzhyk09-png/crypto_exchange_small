# crypto_exchange_small

Выгрузка **крипто-обменников и P2P-чатов** из публичных страниц TGStat
плюс воспроизводимая механика парсинга.

Репозиторий приватный. Внутри — только публичная статистика каналов/чатов;
токенов, паролей и доступов нет.

## Что внутри

```
out/
  crypto_exchange_small.xlsx     # лист «обмен + есть админ», 3 канала
  crypto_exchange_abroad.xlsx    # лист «Русские за границей», 11 строк
  crypto_theme_abroad.xlsx       # лист «Русские за границей», 10 чатов
  crypto_theme_live.xlsx         # лист «LIVE каналы», 8 каналов
  result_tg_links.txt            # 3 ссылки (обмен + админ)
  exchange_crypto.txt            # 4 ссылки (обменники)
  abroad_ru.txt                  # 10 ссылок (чаты за границей)
  crypto_theme_live.txt          # 8 ссылок (LIVE-каналы)
parsing/
  tgstat_parser.py               # реконструкция парсера TGStat
  queries.txt                    # примеры поисковых запросов
  requirements.txt
```

### Колонки

| Колонка | Что значит |
| --- | --- |
| `Ссылка` | ссылка на канал/чат в Telegram или на карточку TGStat |
| `Тип` | `channel` или `chat` |
| `Название` | название |
| `Подписчики` | число подписчиков/участников |
| `ERR%`, `ERR24%` | вовлечённость за всё время и за 24 часа |
| `Просм/пост` | средний охват одного поста |
| `Язык`, `Гео` | язык и география аудитории по TGStat |
| `Контакт (из описания)` / `Контакт админа` | `@handle` из описания |
| `Описание` | текст описания канала/чата |

## Механика парсинга

Оригинальные скрипты в папке не сохранились — остались только выгрузки.
`parsing/tgstat_parser.py` восстанавливает пайплайн по структуре листов и по
рабочему парсеру `tg_parser_bot`, которым собирались эти же данные.

1. **Поиск.** `https://tgstat.ru/channels/search` для каналов и
   `https://tgstat.ru/chats/search` для чатов.
2. **Фильтры:**
   - категория `crypto` (для части запросов — `economics`/`business`);
   - язык `3` — русский;
   - подписчики `300 — 9 000` — отсекаем совсем мелкие и крупные каналы;
   - поисковое слово: `обмен`, `обменник`, `p2p`, `crypto exchange`,
     `usdt обмен` и т.п. (см. `parsing/queries.txt`);
   - галочка «искать в описании».
3. **Сбор карточек.** Из выдачи берутся `href` вида `/channel/@user` и
   `/chat/@user`, название, тип и текст карточки; подписчики вытаскиваются
   регуляркой из текста карточки.
4. **Обогащение.** Для каждого `@user` открывается страница
   `https://tgstat.ru/{channel|chat}/@user`:
   - описание — между строкой `@user` и блоком «Связанные каналы»;
   - гео и язык — из «Гео и язык канала/чата»;
   - контакты — все `@handle` из описания; контакт считается админским,
     если рядом есть `admin`, `поддержка`, `обмен`, `заказать`, `писать` и
     т.п.
5. **Статистика.** Для каналов открывается `/stat`: `ERR%`, `ERR24%`, охват
   одного поста. Для чатов шаг пропускается.
6. **Разметка:**
   - `LIVE` — `ERR` от 16 до 100% **и** охват поста ≥ 150;
   - `DEAD` — охват ниже 150;
   - «есть админ» — в описании найден контакт в админском контексте;
   - «за границей» — гео не Россия (ОАЭ, Сербия, Киргизия, Аргентина,
     Таиланд, «Весь мир»).
7. **Экспорт.** Каждый срез пишется отдельным листом `.xlsx`; рядом
   сохраняется `.txt` со ссылками.

Между запросами пауза 45–75 секунд, иначе TGStat показывает капчу. Работа
идёт через уже авторизованный Edge по CDP
(`--remote-debugging-port=9222`).

## Как воспроизвести

```bash
pip install -r parsing/requirements.txt

"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" \
  --remote-debugging-port=9222 \
  --user-data-dir="%USERPROFILE%\AppData\Local\Temp\opencode\edge_profile"

# Каналы-обменники, русский язык, 300–9000 подписчиков
python parsing/tgstat_parser.py \
  --query "обмен" --query "обменник" --query "crypto exchange" \
  --category crypto --language 3 --kind channel \
  --subs-from 300 --subs-to 9000 \
  --err-min 16 --views-min 150 \
  --out out/parsed_exchange.xlsx

# Чаты русскоязычной аудитории за границей
python parsing/tgstat_parser.py \
  --query "обмен" --query "p2p" --query "usdt" \
  --category crypto --language 3 --kind chat \
  --subs-from 300 --subs-to 9000 \
  --out out/parsed_abroad.xlsx
```

## Ограничения

- TGStat меняет вёрстку и включает антибот — селекторы могут потребовать
  правки; при капче скрипт останавливается с понятной ошибкой.
- `ERR` и охват есть только у каналов; у чатов эти поля пустые.
- Гео/язык TGStat определяет не всегда — часть ячеек пустая.
- Выгрузки — снимок на дату сбора, статистика в TGStat меняется.
